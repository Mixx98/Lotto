# 🎱 Lotto

역대 로또 당첨 번호 데이터를 바탕으로 **번호를 뽑고, 저장하고, 당첨 여부를 확인**하는 콘솔 프로그램입니다.

## 주요 기능

| 메뉴 | 기능 |
| --- | --- |
| 1. 번호 뽑기 | 역대 당첨 번호 표에서 무작위로 숫자를 골라 중복 없는 6개 번호 생성 → `list.txt`에 새로 저장하거나 이어서 추가 |
| 2. 번호 비교하기 | 이번 회차 당첨 번호 6개 + 보너스 번호를 입력하면 저장된 번호마다 **1등 ~ 5등 / 꽝** 판정 |
| 3. 저장된 번호 보기 | `list.txt` 내용 출력 |
| 4. 종료 | |

> 번호를 완전 무작위가 아니라 **역대 당첨 번호 표에서 뽑기 때문에**, 자주 나온 번호일수록 뽑힐 확률이 높습니다.

## 파일 구조

```
├── Lotto.py    # 메인 프로그램
└── excel.csv   # 동행복권 회차별 당첨번호 데이터 (EUC-KR)
```

## 사용 기술

`Python` `pandas`

## 실행 방법

1. [동행복권 당첨번호 페이지](https://dhlottery.co.kr/gameResult.do?method=byWin)에서 1회 ~ 최신 회차 엑셀을 받아 `excel.csv`로 저장합니다. (포함된 파일은 1027회까지)
2. 실행

   ```bash
   pip install pandas
   python Lotto.py
   ```
